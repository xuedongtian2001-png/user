# Prompts for Academic Writing

Source: https://github.com/ahmetbersoz/chatgpt-prompts-for-academic-writing

## How to use

1. Open `references/prompts.md` and find the section matching the task (Brainstorming; Article Sections — title, keywords, abstract, outline, introduction, literature review, methodology, experiments, results, discussion, conclusion, future work; Improving Language; Summarization; Plan/Presentation; Working with Documents).
2. Pick the closest prompt template and fill in its `[PLACEHOLDERS]` with the user's topic, text, or field.
3. Execute the filled-in prompt yourself on the user's material (you are the model the prompt was written for) and return the result. Offer the filled prompt too if the user wants to reuse it.
4. For long texts, process in chunks, as the source suggests ("Read this [PARAGRAPH]" … "Considering the above text …").
