# Writing AI Conference Papers

Source: https://github.com/hzwer/WritingAIPaper (authors: hzwer, DingXiaoH).

## How to use

1. Read `references/handbook.md` — the full handbook. Sections: **Build a Paper from Scratch** (core idea, framework, introduction, related work), **Readability Improvement** (logical strength, defensibility, shortening confusion time, information density, detail checklist), and an appendix (last-hours checklist, common negative review comments, what to do if rejected, conference list).
2. Read `references/not-good-ideas.md` for a checklist of common mistakes to avoid.
3. Apply the guidance to the user's draft: name which handbook principle each suggestion comes from, and give concrete rewrites rather than abstract advice.

## Key principles (summary)

- A paper's key contribution usually falls into exactly one of: **Insight**, **Performance**, or **Capability**. Identify it and state it early.
- Build the whole framework (title, abstract, figure 1, intro claims, experiments that back each claim) before polishing prose.
- Every claim in the introduction must be supported by an experiment or analysis.
- Optimise for the reader: clear figures with self-contained captions, consistent notation, no unexplained symbols.
